# Defined Art Gallery — Complete React Project

Built from the supplied Pen design with all desktop pages and responsive mobile layouts.

## Pages
- Home
- Shop / category filters / sorting
- Product detail pages
- Collections
- Our Craft / About
- Contact
- Shopping Bag / Cart

## Interactions
- Hash-based client-side routing
- Product/category links across navigation, cards and footer
- Product detail quantity controls
- Add to bag from product cards and product pages
- Persistent cart via localStorage
- Dynamic cart quantities/removal/total
- Contact form success state
- Newsletter subscription success state
- Responsive mobile navigation

## Run
```bash
npm install
npm run dev
```
